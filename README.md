# Ledger

A responsive personal expense tracker built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. No build step is required.

## Features

- Add, edit, and delete expenses
- Category and description filtering
- Sort by date or amount
- Spending totals, count, and average
- Category breakdown chart and ranked category summary
- Local browser persistence with `localStorage`
